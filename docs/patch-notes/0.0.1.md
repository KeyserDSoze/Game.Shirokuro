# 0.0.1 — Foundation

- Initial repository architecture aligned with Vuxo boundaries.
- React/TypeScript UI shell with shadcn/ui-style shared components, dark/light/system appearance and Italian/English localization.
- React Three Fiber 3D preview with hexagons and procedural hero placeholder.
- .NET 10 API + hex coordinate model; xUnit, Vitest, Playwright and GitHub Actions quality gates.
- First confirmed gameplay invariant: an authoritative confirmed kill advances a hero from level 1 to level 2; no level 3. Added immutable domain model and xUnit tests (issue #5).
- Indexed 317 original graphic files from a supplied ZIP; added the roster of 14 heroes, a provisional first-mode specification and asset plan (issues #3, #4 and #5). The large original ZIP is not committed.

- Hero roster preview picker with 14 original hero names, accessible keyboard selection, IT/EN and local-only placeholder token; actual artwork appears after importing optimized assets (issue #7).
- Safe, repeatable ZIP-to-WebP importer for 14 portraits and 6 tiles, synthetic archive regression tests in CI (issue #4); original source and derived artwork are not yet committed. CI #42657389085 passed: 18 xUnit, 20 Vitest, 5 Playwright, 7 Python importer tests; frontend and .NET builds successful.

- Added a server-side Domain snapshot and Application observation projector with default-deny visibility grants. Other players' planned destinations are absent by design from network-facing DTOs (issue #8), with xUnit tests for unauthorized observations and JSON redaction.

This version is not a playable release. The PvP/PvE rules and hidden information are pending detailed design input. Issue #1 was completed via PR #2 (squash merge 6f0bcea). CI run #42649038047 passed: 11 xUnit, 12 Vitest and 3 Playwright tests, plus .NET and frontend builds. The 3D models remain code-only placeholders.
